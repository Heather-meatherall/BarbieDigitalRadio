# BarbieDigitalRadio

A music player themed after the Babrie Boombox from the 1990s. Features draggable* cds that spin and play music. 


Audio taken from <a href="https://www.youtube.com/watch?v=7ORydOoLEUI">The Electronic Toy Archive<a/>

*drag and drop feature currently doesn't work on mobile
